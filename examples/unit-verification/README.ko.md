# 가상 단위 검수 예제

[English](README.md)

`checks.json`의 14개 대조값은 이번 작업에서 새로 만든 가상 값입니다. 해당 JSON 자체가 원본이며, `sourceRef`의 JSON 포인터는 같은 파일의 행과 포장 정의를 가리킵니다. 실제 엑셀·회사 자료는 없습니다. 제공된 값의 환산 검사 예제이며 엑셀 자동 추출 검증이 아닙니다.

```text
python skills/ppt-to-html/scripts/unit_audit.py examples/unit-verification/checks.json --output examples/unit-verification/report.json
```

| 대조 항목 | 결과 |
|---|---|
| 1.25 m → 1,250 mm | 통과 |
| 2 m² → 20,000 cm² | 통과 — 환산 계수를 제곱 |
| 2.5 L → 0.0025 m³ | 통과 |
| 1,200 kg → 1.2 t | 통과 |
| 90분 → 1.5시간 | 통과 |
| 36 km/h → 10 m/s | 통과 |
| 720개/시간 → 12개/분 | 통과 |
| 800원/kg → 0.8원/g | 통과 |
| 1 kWh → 3,600,000 J | 통과 |
| 3박스 → 24개, 가상 포장 정의 ‘박스당 8개’와 출처 있음 | 통과 |
| 1 m → 1 m² | 확인 필요 — 차원이 다름 |
| 3박스 → 24개, 포장 정의 없음 | 확인 필요 — 환산 기준 누락 |
| crate → crate | 확인 필요 — 같은 단위명이더라도 미지원 업무 단위 |
| 섭씨 → 켈빈 | 확인 필요 — 오프셋이 있는 온도 환산 미지원 |

전체 보고서는 의도적으로 **확인 필요**입니다. 실행 종료 코드만 보지 말고 각 행을 검토하세요. 원본·표시 값, 단위명, 차원, 환산 계수와 정의 출처를 보존합니다. 통과는 제공된 값의 계산 범위이며 원본 추출과 의미 일치까지 보장하지 않습니다. 월의 일수·환율·밀도·알 수 없는 단위는 추정하지 않습니다.

캠페인 HTML에도 결과를 넣으려면 검토한 JSON의 선택 항목 `unitChecks`에 이 목록을 넣습니다. `build_analysis.py`가 `unitAudit`을 새로 계산해 포함하고 근거 화면에 표시합니다. HTML 저장에도 보존됩니다. 기존 원화 차트를 길이·질량 차트로 바꾸는 기능은 아니며, 다른 차트·데이터 모델에는 별도로 검증한 변환 규칙이 필요합니다.
