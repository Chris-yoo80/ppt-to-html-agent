# 전체 발표 예제

에이전트가 발표의 일부 장면만 만드는 것으로 오해하지 않도록, 처음부터 끝까지 이어지는 가상 발표 예제입니다. 총 7장으로 목차, 개요, 본문 3장, 타임라인, 결론을 담았습니다.

실제 업무 발표의 흐름에서 구조만 참고했습니다. 청중에게 전체 순서를 안내하고, 범위와 근거를 설명한 뒤 실행안과 일정을 제시하고 의사결정으로 마칩니다. 회사명, 실제 수치, 기존 문구, 내부 자료는 재사용하지 않았습니다.

모든 수치는 새로 만든 가상 데이터입니다. 도달 1,500명, 클릭 300회, 구매 45건이며 구매/클릭은 15.0%, 구매/도달은 3.0%입니다. 인원과 이벤트는 단위가 다르므로 각각 명시했습니다.

국·영문을 함께 생성합니다.

```sh
python tools/build_full_presentation.py
```

결과: `docs/full-presentation.html`, `docs/full-presentation.en.html`.
