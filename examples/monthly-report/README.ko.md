# 반복 생성하는 월간 매출 리포트

새로 만든 가상 데이터만 사용한 예제입니다. 회사·고객·내부 수치는 포함하지 않습니다. 9월과 10월 모두 표지, 핵심 요약, 채널 구성, 주간 타임라인, 결론의 동일한 5장 구조를 사용합니다.

두 달·두 언어 결과를 모두 생성합니다.

```sh
python tools/build_monthly_report.py
```

`examples/monthly-report/YYYY-MM.json`을 추가한 뒤 새 월만 생성합니다.

```sh
python tools/build_monthly_report.py --month YYYY-MM
```

같은 명령이 대응하는 `YYYY-MM.xlsx`, 한·영 발표 JSON과 오프라인 HTML을 만듭니다. 공개 전에는 엑셀과 JSON을 함께 검토하세요. 지난달 합계를 그대로 재사용하면 안 됩니다.

## 수치 검수

| 항목 | 9월 | 10월 | 근거 |
|---|---|---|---|
| 단위 | 통과 | 통과 | 매출·평균 주문금액은 KRW, 주문은 건수입니다. 국문은 KRW ÷ 10,000을 만원으로, 영문은 KRW ÷ 1,000,000을 KRW M으로 표시합니다. |
| 분모 | 통과 | 통과 | 평균 주문금액 = 전체 매출 ÷ 전체 주문. 채널 비중 = 채널 매출 ÷ 월 전체 매출입니다. |
| 필터·범위 | 통과 | 통과 | `Sales!A1:D13`; 월별 주차 4개, 채널 3개, 총 12개 행입니다. |
| 반올림 | 통과 | 통과 | 원본 정수를 먼저 합산합니다. 금액은 화면에서만 소수점 한 자리로 반올림하며 원본 KRW는 출처 문구에 유지합니다. |
| 출처 | 통과 | 통과 | 모든 장면에 `YYYY-MM.xlsx / Sales!A1:D13`을 표시합니다. |
| 모션 끔·인쇄 | 공통 플레이어 테스트 통과 | 공통 플레이어 테스트 통과 | 제목·수치·설명·출처가 최종 단계와 인쇄 복제본에 HTML 텍스트로 남습니다. 저장된 PDF 배치는 별도 시각 검수 대상입니다. |

검토한 합계는 9월 **주문 1,218건, 매출 70,995,000원, 평균 주문금액 58,288.18원**, 10월 **주문 1,471건, 매출 91,607,000원, 평균 주문금액 62,275.32원**입니다. 엑셀과 JSON, 생성 결과의 일치는 테스트에서 확인합니다.
