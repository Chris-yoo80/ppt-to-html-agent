# 새 발표 시작 질문

아래 질문을 한 번에 간결하게 묻는다. 이미 받은 답은 채워서 보여주고 다시 묻지 않는다. 사용자가 '추천 설정으로'라고 하면 추천값을 선택한 것으로 기록한다. 설정은 작업 폴더의 brief에 저장할 수 있으나, 사용자 자료와 함께 공개 예제로 커밋하지 않는다.

| 질문 | 선택 예시 | 추천값 |
|---|---|---|
| 1. 발표 목적·청중·시간은? | 보고 / 제안 / 강의 / 제품 소개, 청중, 목표 분량 | 원문에서 추정 가능한 부분만 제안하고 확인 |
| 2. 화면 비율과 기준 크기는? | 16:9 1600×900 / 16:9 1920×1080 / 4:3 / 직접 지정 | 16:9 1600×900, 창에 비율 유지 맞춤 |
| 3. 글꼴과 분위기는? | 시스템 글꼴 / 지정 글꼴, 화면 구성: `consulting`(한 화면 여러 패널·상단 장 탭) / `executive`(경영진 스토리·스포트라이트·하단 장 탭) / `default`(짧은 카드형) | 보고·검토·제안은 `consulting` 또는 `executive` 구성형 장면, 짧은 발표는 `default`. 시스템 한글 sans-serif |
| 4. 움직임은 얼마나 자주 넣을까? | 없음 / 핵심 화면만 / 대부분 화면 | 핵심 화면만, 의미를 설명하는 동작 중심 |
| 5. 단계는 어떻게 진행할까? | 클릭·키보드 / 자동 / 둘 다 | 수동 기본 + 선택적 자동 재생, 마지막에 정지 |
| 6. 점·선·면 모션은 어디에 넣을까? | 사용 안 함 / 적합한 화면에 AI 제안 / 장면 지정 | 적합한 장면을 AI가 제안한 뒤 구성에 반영 |
| 7. 최종 산출물과 사용 환경은? | 오프라인 단일 HTML / 편집용 소스 포함 / 인쇄·PDF 요청 | 오프라인 HTML + 편집용 소스, MP4는 후속 버전 |
| 8. PDF도 필요한가? | 필요 없음 / 발표 장면 전체 / 분석 자료 별도 출력 | 장면마다 모든 설명 단계를 펼쳐 A4 가로 한 페이지, 분석은 현재 필터 기준으로 별도 출력 |
| 9. 백업자료는 무엇을 어디에 넣을까? | 자료 파일·경로, 관련 장면·주제, 탭 이름, 추가 자료 / 별도 HTML / 둘 다 | 검토한 자료만 발표 전체의 추가 자료 탭에 포함, 원본 PPT·엑셀 첨부는 별도 선택 |

## 10. 레퍼런스 디자인

사용자에게 참고할 웹사이트·GitHub 저장소·HTML·이미지·이름이 붙은 스타일이 있는지 묻는다. 없다면 `없음` 또는 추천 프리셋을 선택할 수 있다.

함께 기록할 항목:

- 참고 출처 또는 프리셋: `slide-story`, `dashboard`, `data-motion`, `hybrid`
- 적용 범위: 전체 분위기 / 색상 / 글꼴 계층 / 레이아웃 / 카드·차트 / 모션 / 특정 장면
- 유사도: 분위기만 참고(추천) / 레이아웃 적극 참고 / 허용된 코드 재사용
- 권한: 시각적 참고만 / 확인한 재사용 라이선스 / 사용자 소유 / 확인 필요

URL을 실제로 열지 못했다면 확인했다고 쓰지 않고 HTML 내보내기나 화면 캡처를 요청한다. 공개 웹페이지라는 이유만으로 코드·이미지·아이콘·브랜드·예제 데이터를 복사하지 않는다. 코드 재사용은 라이선스 이름과 근거 URL이 모두 있을 때만 진행한다. 자세한 절차는 [design-references.md](design-references.md)를 따른다.

## 설정 해석

PDF는 브라우저의 인쇄 / PDF 버튼에서 PDF 저장 대상을 선택한다. 발표는 현재 단계와 무관하게 모든 장면을 출력한다. 분석·백업 HTML은 별도로 출력하며 자동 합본하지 않는다. 애니메이션과 슬라이서는 정적 결과로 남는다. 취소 후 원래 단계로 돌아오며 자동 재생은 정지한다.

- 화면 크기는 기준 좌표와 실제 표시 크기를 구분한다. 1600×900 무대도 다른 창 크기에서 비율을 유지할 수 있다. 작은 화면에서 글자가 지나치게 작아지는 문제는 별도로 확인한다.
- 지정 글꼴은 설치 여부와 배포 가능한 글꼴 파일 보유 여부를 확인한다. 오프라인용으로 원격 폰트를 필수 의존하지 않는다.
- '핵심 화면만'은 고정 비율로 적용하지 않는다. 인과관계, 순서, 상태 변화 설명에 도움이 되는 장면에 사용한다.
- 자동 재생 시간은 텍스트 읽기와 모션 완료 시간을 함께 고려한다. 화면을 바꿀 때 기존 타이머와 애니메이션 작업을 정리한다.
- 원문 보존과 재구성 정도가 불명확하면 추가로 확인한다. 사용자가 별도 지시하지 않으면 의미·수치·근거는 보존하고 레이아웃과 단계 구성은 재설계한다.
- 첫 버전은 HTML 안의 모션을 지원하고 MP4 저장은 제공하지 않는다. MP4 요청에는 후속 기능임을 설명하고 HTML 제작과 영상 인코딩을 같은 기능으로 약속하지 않는다.
