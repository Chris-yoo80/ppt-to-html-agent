# 점·선·면 모션 그래픽

## 표현과 목적

HTML 안에서 SVG/CSS 또는 필요한 경우 Canvas로 간결한 모션 그래픽을 만든다. 다음은 표현 기법이며, 실제 시뮬레이션이나 최적화 계산을 수행한다는 뜻은 아니다.

| 기법 | 설명할 수 있는 내용 |
|---|---|
| 점 등장·집결·이동 | 항목, 사건, 데이터의 유입과 통합 |
| 선 그리기·점선 흐름 | 연결, 순서, 정보 전달 |
| 경로를 따라 점·도형 이동 | 처리 과정과 이동 순서 |
| 면 분할·합치기·색 변화 | 영역, 상태, 역할의 변화 |
| 도형·차트 단계 누적 | 비교 근거와 결론의 순차 설명 |

## 장면 설계

장면마다 '전달할 한 문장 → 초기 상태 → 변화 순서 → 마지막 상태'를 정의한다. 동작은 읽기와 설명을 도와야 한다. 주요 라벨과 핵심 수치는 움직이는 요소 위에 불안정하게 겹치지 않게 둔다. 의미 없는 지속 루프를 기본값으로 사용하지 않는다.

수동 발표에서는 클릭 한 번이 의미 있는 한 단계가 되도록 한다. 자동 재생에서는 글을 읽을 시간과 연출 시간을 확보한다. 뒤로 이동하거나 장면을 재진입했을 때 상태가 결정적으로 복원되게 하고, 화면을 떠날 때 타이머와 requestAnimationFrame을 중지한다.

사용자의 reduced-motion 설정에서는 이동·점멸을 줄이고 마지막 상태나 즉시 전환으로 의미를 유지한다. 색만으로 차이를 전달하지 말고 라벨·형태·선 패턴을 함께 사용한다.

## 데이터와 출력

가상 데이터로 만든 도식에는 '개념 예시 · 실측 수치 아님'처럼 성격을 표시한다. 장식용 차량 이동이나 경로를 실제 계산 결과로 설명하지 않는다. 원본 회사 영상·지도·로고를 공개 예제에 재사용하지 않는다.

HTML 모션은 실시간 브라우저 표현이다. MP4는 별도의 프레임 캡처·인코딩 단계가 필요한 산출물이다. 영상 출력이 합의되고 도구가 준비된 경우에만 해상도·시간축·프레임률·최종 프레임을 검증한다. 무음 영상을 기본으로 제안하되 사용자가 요청한 음성·배경음 범위는 별도로 합의한다.
