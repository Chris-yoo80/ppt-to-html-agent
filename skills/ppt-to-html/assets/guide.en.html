PPT TO HTML AGENT / USER GUIDE

1. Install the skill

Before you start: Claude Code or Codex must be installed and signed in, and Python 3.10+ is needed for bundled helpers. Check with python --version on Windows or python3 --version on macOS/Linux; macOS/Linux users type python3 wherever examples say python.

Easiest: unpack the ZIP, open your project folder in Claude Code or Codex, and ask the agent to install it:

Install the ppt-to-html folder from my Downloads folder as a Claude Code skill for this project.
The result must be .claude/skills/ppt-to-html/SKILL.md, not one folder deeper.
Then check the path and tell me how to invoke the skill.

For Codex, say “Codex skill” and .agents/skills/ppt-to-html/SKILL.md. To copy the folder yourself, put the complete ppt-to-html/ folder in one of these locations:

HostOne project (inside your project folder)Every project (user folder)Invoke

Codex.agents/skills/ppt-to-html/~/.agents/skills/ppt-to-html/$ppt-to-html
The result must be skills/ppt-to-html/SKILL.md, not one folder deeper. Windows “Extract All” adds a folder named after the ZIP; extract to the skills folder itself or move the inner ppt-to-html folder up one level.

Folders starting with a dot are hidden: on Windows use File Explorer → View → Show → Hidden items; on macOS press Cmd+Shift+. in Finder. ~ is your user folder, such as C:\Users\name or /Users/name.

Open your project folder in the host (restart it if it was running). Type / in Claude Code or $ in Codex and check that ppt-to-html appears. To update, delete the old folder and install the new one. The website does not upload or convert files. Your AI provider’s subscription or usage charges still apply.

2. Start with the brief

Use the ppt-to-html skill to reconstruct this PPT as an HTML presentation.
Ask only for missing settings: purpose, audience, time, screen size,
typeface, motion frequency, playback and supporting material.
I want marketing analysis as additional HTML inside the presentation.
Place controls and slicers on the left, visual results on the right.
Show the outline and one representative scene before building the rest.

For the supporting analysis, first provide the workbook as a chat attachment or accessible local path. The agent asks which sheets/ranges to use and where to place the analysis: Additional resources, a standalone HTML link, or both. Specify the related scene/topic and resource tab label. Then agree on period, currency, KPI definitions, filters, screen, font, language and sharing scope. This is an agent conversation step, not a workbook upload control on this website. The current player uses a presentation-wide resources button; scene-specific controls require a separate extension. Accept recommended defaults in one answer if you prefer. Reuse answers already supplied.

5. Explore the marketing supplement

On first open, choose purpose, priority metrics, viewing context, font and CSV controls. On the left, select period, channels and market. On the right, review KPIs, revenue/spend trends, conversion counts and channel ROAS. Add the source detail table only when needed.

What-if sliders keep source results unchanged. They assume constant cost per click and channel mix, with separate conversion and order-value multipliers. These are hypothetical scenarios, not forecasts. ROAS uses total revenue / total spend; conversion uses total purchases / total clicks. A zero denominator is unavailable.

Save HTML retains the current brief, filters and assumptions in one file. CSV downloads are opt-in in Initial setup. The source workbook is not automatically attached.

6. Share the right information

Offline HTML contains the data needed for its charts. Turning off CSV buttons does not remove that data or secure confidential information.

Review notes, hidden sheets, embedded files, personal information, internal paths and source attachments before sharing. Include raw PPT or Excel files only when explicitly selected and reviewed. Public examples in this project use newly authored fictional data.

7. PDF output and backup tabs

At the start, tell the agent whether you need a deck PDF, analysis PDF, or both. Specify backup files, their related scene/topic, tab labels and placement (Additional resources, a separate HTML link, or both). The agent asks for missing answers and reuses known settings. Raw PPT/Excel attachments remain a separate opt-in choice.

In the presentation, choose Print / PDF to preview all scenes with every reveal visible, one scene per A4 landscape page. Choose Print / Save as PDF, select the browser's PDF destination, and save. Return to the same presentation step; autoplay remains paused. Browser headers/footers can be disabled in the print dialog.

Print supporting analysis separately using its Print / PDF control, or open its standalone HTML. It uses the current filters and enabled detail/scenario sections. Motion and slicers become static results. Backup resources are labeled HTML tabs (up to eight); the example includes source/calculation notes. They are not automatically merged into the deck PDF. Review each resource's own print layout before sharing.

8. Verify the numbers

Before delivery, compare units and any displayed conversion, denominators, filters/ranges, rounding and source references against the original workbook. Unit review includes length, area, volume, mass, time, speed, energy/power and compound/business units, not just money. The bundled unit_audit.py checks declared conversions such as m/mm, m²/cm², L/m³, kg/t, km/h→m/s, item/h and KRW/kg. Box/item conversions need a positive per-source-unit factor and its definition source. Unknown units, incompatible dimensions, Celsius/Fahrenheit offsets, exchange rates and calendar months remain Needs review. A passed arithmetic comparison is not an automatic workbook audit; campaign charts remain KRW-based. In Definitions and evidence, inspect source units, conversion precision, rate definitions, current filters, source totals and sheet/range. Amounts are sourced in KRW; Korean views abbreviate amounts of at least KRW 10,000 in units of 10,000 (max one decimal), English views abbreviate amounts of at least KRW 1,000,000 in millions (max two decimals). Trend axes use those divisors with max one decimal; rates use max two decimals. Ratios use the same selected group, not an average of row ratios.

The agent's final report must include six rows: units / denominators / filters and ranges / rounding / motion-off and print retention / provenance, each with Passed or Needs review and supporting evidence. Metadata describes the implementation; it does not automatically certify agreement with your workbook. Rounded parts may differ from the rounded total; calculations retain source precision. Missing source definitions or checks remain Needs review.

9. Read without motion

The motion demos keep a static Key facts summary below the player: title, explanation, all four phases, figures and qualifications. Earlier headline figures remain available at the final frame. Use Turn motion off to stop animation and keep manual chapter/timeline navigation. System reduced motion takes precedence. Switching it on pauses at the current time; turning it off does not resume playback automatically.

In the presentation, reduced motion or motion=none reveals all items in the current scene while retaining its navigation step. Autoplay is disabled under system reduced motion. The demo's Print / PDF previews all three summaries. The presentation previews every scene, including staged content. Return to the same story/time or presentation step, with playback paused. Saved-PDF verification is separate.

10. Supported scope

The skill redesigns the narrative rather than reproducing PPT pixels. Basic PPTX extraction reads text, tables and separate notes; OCR, SmartArt text and chart workbook interpretation are not included. The campaign starter accepts a reviewed data model; it does not automatically interpret arbitrary Excel formulas, macros or external connections. Other workbook types require a separately validated adapter. MP4 export is deferred.

Static checks, host CLI tests and real browser checks cover different things. See the verification record for the exact observations; a single fictional example does not establish compatibility with every workbook or browser.

11. Use a design reference

Provide a website URL, GitHub repository, local HTML/image, named style or one of four presets: slide-story, dashboard, data-motion and hybrid. State whether to apply mood, color, typography, layout, cards, charts, motion, navigation or selected scenes.

The default is visual inspiration. The agent extracts abstract rules and rebuilds them with project-owned HTML/CSS/SVG; it does not copy branding, text, images, icons, sample data, DOM or CSS. Code or asset reuse requires a verified license and source URL. The output stays an offline single HTML file and records decisions in design-reference.json.

12. Report-style scenes and charts

For reports, reviews and proposals the agent builds composed scenes: two or three panels per screen, each with the visual its evidence needs. The title states the conclusion, a summary bar carries the key figures and a Key Message or insight bar closes the screen.

PartWhat it does
ChartsBar, line, funnel, donut and waterfall, drawn to scale from zero. Funnel rates and donut shares are computed from the data.
Spotlight stepsEach click outlines the panel being explained and dims the rest, so the context stays visible.
ComponentsKPI tiles, tables with highlighted rows, Gantt, process flow, status timeline, progress bars and custom SVG illustrations.
Chapters and backupChapter tabs, a breadcrumb, backup scenes in 자료실 and jump buttons that return to the exact step.

The design follows the content rather than a template. The agent chooses a visual direction from the content, audience and brand, uses design skills installed in your AI tool when available (for example frontend-design, UI/UX or data-visualization skills) and varies the composition from scene to scene. The consulting (dense panels, index tabs on top) and executive (storytelling with spotlight, tabs at the bottom) presets are starting points only. Tell the agent your brand colors or a reference you like; licensed icons and chart patterns can be reused, and look-only galleries are used for inspiration.

Every number in a chart, bar width or illustration is calculated from the source. Ask for the numeric review before delivery.

13. Fix text and leave memos on screen

Every presentation has review tools in the top-right corner.

ToolUse
Edit / EShows every step and lets you click titles, summary bars, panel text, card labels and key messages to change them. Layout, styles and chart data stay locked.
Memo / MClick any element and write a change request, such as “shorten this”, “check the source” or “use a bar chart”. A numbered badge marks it.
ReviewLists edits (before and after) and memos, then Save edited HTML or Export changes (JSON).

Save edited HTML creates a new offline file that reopens with your edits and memos. To update the source so the next build keeps your changes, give deck-edits.json to the agent and ask it to apply the review. The agent applies only text that still matches what you saw, answers each memo and reports anything it could not apply.

If an edit changes a number or unit, a banner warns you. Charts, bar widths and totals are not changed by text edits; the agent re-checks them against the source and updates them.

Mixed text (for example a number with a separately styled unit) and text inside drawings are not editable directly; leave a memo instead. Printing always shows the audience view.
