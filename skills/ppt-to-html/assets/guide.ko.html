PPT TO HTML AGENT / USER GUIDE

발표에 근거 자료까지,
HTML로 함께.

스킬은 AI 작업 환경에서 사용합니다. 발표는 간결하게 이어가고, 필요한 순간 추가 HTML을 열어 분석 근거를 확인하세요.

스킬 ZIP 내려받기발표 + 추가 자료 예제보충 분석 HTML만 열기

1. 스킬 설치하기

스킬 ZIP을 내려받아 ppt-to-html/ 폴더 전체를 작업 프로젝트 안에 넣습니다.

도구프로젝트 안 설치 위치호출
Claude Code.claude/skills/ppt-to-html//ppt-to-html
Codex.agents/skills/ppt-to-html/$ppt-to-html

해당 프로젝트를 AI 도구에서 열고 접근 가능한 PPTX를 전달합니다. 보조 도구에는 Python 3.10 이상이 필요합니다. 소개 사이트는 파일 업로드·변환 서비스를 제공하지 않습니다. AI 구독료·사용료는 사용하는 서비스의 조건을 따릅니다. 설치 링크는 인터넷 연결이 필요합니다.

2. 첫 요청과 기초 설정

ppt-to-html 스킬로 이 PPT를 HTML 발표로 재구성해줘.
목적·청중·시간·화면 크기·글꼴·모션 빈도·재생 방식 중
아직 알려주지 않은 설정만 질문해줘.
마케팅 분석은 발표 안에서 여는 추가 HTML로 넣어줘.
왼쪽에는 조정값과 슬라이서, 오른쪽에는 결과와 차트를 배치해줘.
전체 제작 전에 목차와 대표 화면 하나부터 보여줘.

보충 분석은 먼저 엑셀을 채팅에 첨부하거나 접근 가능한 로컬 경로로 제공합니다. 에이전트는 사용할 시트·범위와 분석 배치 위치(추가 자료, 별도 HTML 링크, 또는 둘 다), 관련 발표 장면·주제, 자료 탭 이름을 묻습니다. 이후 기간, 통화·단위, 지표 정의, 필터, 화면, 글꼴, 언어, 공유 범위를 정합니다. 이는 에이전트와의 대화 절차이며 이 웹사이트의 엑셀 업로드 기능이 아닙니다. 현재 플레이어는 발표 전체의 추가 자료 버튼을 사용하며, 장면별 버튼은 별도 구현이 필요합니다. “추천 설정으로”라고 한 번에 답해도 됩니다. 이미 전달한 설정은 다시 묻지 않습니다.

3. 기초 화면부터 만들고 확장하기

01 / 설정 합의

목적·원문 의미·기본 배치를 정합니다.

02 / 대표 화면 검토

목차와 대표 장면 또는 차트 하나를 확인합니다.

03 / 필요한 기능 추가

기초 화면을 승인한 뒤 상세표·가정·내보내기를 추가합니다.

결과물은 발표 HTML, 보충 분석 HTML, 편집용 소스입니다. 보충 HTML을 발표 안에 포함할 수 있어, 메인 파일 하나로 서버 없이 오프라인에서 사용할 수 있습니다.

4. 발표와 추가 자료 조작

조작동작
← / →설명 단계를 이동합니다. Home은 처음으로 돌아갑니다.
목차 / G모든 장면과 설명 단계를 열고 원하는 위치로 바로 이동합니다.
질문 표시 / B현재 장면과 정확한 설명 단계를 저장합니다. Shift+B는 전체 질문 표시를 엽니다.
질문 복귀 / R가장 최근 표시로 돌아갑니다. 이전 표시는 질문 목록에서 선택합니다.
자동 재생 / A선택적으로 자동 진행합니다. 기본은 마지막에 정지입니다.
추가 자료자동 재생을 멈추고 발표 위에 보충 HTML을 엽니다. 같은 세션의 발표 위치와 질문 표시는 유지됩니다.
발표로 돌아가기 / Escape열기 전 발표 단계로 돌아옵니다. 자동 재생은 직접 다시 켭니다.
자료 탭마케팅 분석과 HTML 설명서를 선택합니다.

5. 마케팅 분석 화면 사용하기

처음 열면 분석 목적, 우선 지표, 화면, 글꼴과 CSV 설정을 선택합니다. 왼쪽에서 기간·채널·시장을 고르면 오른쪽 KPI, 매출·광고비 추이, 전환 수치, 채널별 ROAS가 함께 바뀝니다. 원본 상세표는 필요할 때 추가합니다.

가정 시나리오는 원본 성과를 변경하지 않습니다. 클릭당 비용과 채널 비중을 고정한 상태에서 광고비·전환율·객단가 배수를 적용하며, 실제 예측을 뜻하지 않습니다. ROAS는 전체 매출 ÷ 전체 광고비, 전환율은 전체 구매 ÷ 전체 클릭입니다. 분모가 0이면 값을 계산하지 않습니다.

HTML 저장은 현재 기초 설정·필터·가정을 단일 파일에 보관합니다. CSV는 기초 설정에서 허용한 경우에만 내려받을 수 있습니다. 원본 엑셀 파일은 자동 첨부하지 않습니다.

6. 공유 범위 확인하기

오프라인 HTML에는 차트를 계산하는 데이터가 포함됩니다. CSV 버튼을 끄는 것으로 데이터가 제거되거나 기밀 자료가 보호되지는 않습니다.

공유 전 발표자 메모, 숨김 시트, 첨부 파일, 개인정보, 내부 경로를 확인합니다. 원본 PPT·엑셀 첨부는 명시적으로 선택하고 검토한 경우에만 포함합니다. 이 프로젝트의 공개 예제는 새로 작성한 가상 자료입니다.

7. PDF 출력과 백업자료 탭

처음에 발표 PDF·분석 PDF 중 필요한 범위와 백업자료 파일, 관련 장면·주제, 탭 이름, 배치 위치(추가 자료·별도 HTML·둘 다)를 정합니다. 에이전트가 빠진 답만 묻습니다. 원본 PPT·엑셀 첨부는 별도로 선택합니다.

발표의 인쇄 / PDF를 누르면 모든 장면과 숨겨진 설명 단계를 펼친 미리보기가 나옵니다. A4 가로 한 장에 장면 하나입니다. 인쇄 / PDF로 저장에서 브라우저의 PDF 저장 대상을 선택하세요. 머리글·바닥글은 인쇄 창에서 끌 수 있습니다. 돌아오면 원래 발표 단계가 유지되고 자동 재생은 정지합니다.

분석 자료의 인쇄 / PDF는 현재 필터와 활성화한 상세표·가정 시나리오를 정적인 결과로 별도 출력합니다. 단독 HTML에서도 사용할 수 있습니다. 백업자료는 이름을 지정한 HTML 탭으로 최대 8개까지 넣을 수 있고, 예제에는 원본·계산 근거 탭이 있습니다. 발표 PDF와 자동 합본하지 않으며, 각 자료의 인쇄 레이아웃을 확인해야 합니다.

8. 수치 검수와 결과 보고

최종 전달 전에 원본 엑셀과 단위·표시 환산, 분모, 필터·범위, 반올림, 출처를 대조합니다. 단위 검수는 금액뿐 아니라 길이·면적·부피·질량·시간·속도·에너지/전력·복합/업무 단위를 포함합니다. unit_audit.py는 m/mm, m²/cm², L/m³, kg/t, km/h→m/s, 개/시간, 원/kg 등 지원하는 단위의 제공된 값을 대조합니다. 박스↔개는 출처가 있는 양수 환산 계수가 필요합니다. 미지원 단위, 차원 불일치, 섭씨·화씨 환산, 환율, 달력상의 월은 확인 필요로 남깁니다. 계산 통과가 엑셀 원본 검증을 대신하지 않으며, 캠페인 차트 자체는 원화 기반입니다. 지표 정의·계산 근거에서 원본 단위, 환산 자릿수, 분모 정의, 현재 필터, 원본 합계와 시트·범위를 확인할 수 있습니다. 원본은 원화이며 국문 금액은 1만원 이상부터 만원 단위 최대 소수 1자리, 영문은 100만원 이상부터 백만원 단위 최대 소수 2자리로 표시합니다. 추이 축은 같은 환산 단위로 최대 소수 1자리, 비율은 최대 소수 2자리입니다. 비율은 같은 선택 범위의 합계로 계산하며 행별 비율을 평균하지 않습니다.

에이전트는 단위 / 분모 / 필터·범위 / 반올림 / 모션 끔·인쇄 정보 유지 / 출처 6개 항목을 각각 통과 또는 확인 필요 / 근거·남은 확인 표로 보고합니다. 메타데이터가 있다는 이유만으로 원본 일치를 통과 처리하지 않습니다. 반올림한 부분 합계는 표시된 전체 합계와 다를 수 있으며 원본 정밀도로 계산합니다. 원본 정의나 검증이 빠진 항목은 확인 필요로 남깁니다.

9. 모션 없이 읽고 인쇄하기

모션 데모 아래의 핵심 정보 요약에는 제목·설명·4단계·핵심 수치·주의사항이 남습니다. 재생 마지막에도 처음의 대표 수치를 읽을 수 있습니다. 모션 끄기로 움직임을 멈춰도 단계·타임라인은 직접 이동할 수 있습니다. 시스템의 모션 줄이기 설정이 우선하며, 도중에 켜면 현재 시점에서 멈춥니다. 설정을 해제해도 자동 재생하지 않습니다.

일반 발표는 모션 줄이기 또는 motion=none에서 현재 장면의 모든 항목을 보여주며 단계 위치는 유지합니다. 시스템 모션 줄이기에서는 자동 재생을 비활성화합니다. 모션 데모의 인쇄 / PDF는 세 예제의 전체 요약을, 발표의 인쇄 미리보기는 모든 장면과 설명 단계를 보여줍니다. 돌아오면 원래 주제·시점 또는 발표 단계가 유지되고 재생은 정지합니다. 저장된 PDF 검증은 별도입니다.

10. 지원 범위와 한계

PPT의 픽셀 배치를 복원하기보다 설명 구조를 재설계합니다. 기본 PPTX 추출기는 텍스트·표·메모를 구분해서 읽으며 OCR, SmartArt 텍스트, 차트 워크북 해석은 지원하지 않습니다. 캠페인 예제는 검토한 데이터 모델을 입력받으며, 임의의 엑셀 수식·매크로·외부 연결을 자동 변환하지 않습니다. 다른 형태의 엑셀에는 별도로 검증한 변환 규칙이 필요합니다. MP4 출력은 후속 기능입니다.

정적 검사, AI 도구 실행 검사, 실제 브라우저 검증은 서로 다른 범위입니다. 구체적인 결과는 검증 기록을 확인하세요. 가상 예제 하나의 통과가 모든 파일·브라우저의 호환성을 보장하지 않습니다.

11. 디자인 레퍼런스 사용

웹사이트 URL, GitHub 저장소, 로컬 HTML·이미지, 스타일 이름 또는 네 가지 프리셋(slide-story, dashboard, data-motion, hybrid)을 전달하세요. 분위기, 색상, 글꼴, 레이아웃, 카드, 차트, 모션, 내비게이션, 특정 장면 중 무엇을 적용할지도 지정할 수 있습니다.

기본 방식은 시각적 영감입니다. 에이전트는 추상적인 디자인 규칙을 분석해 프로젝트 소유 HTML/CSS/SVG로 새로 만들며 브랜드, 문구, 이미지, 아이콘, 예제 데이터, DOM, CSS를 복사하지 않습니다. 코드나 자산 재사용에는 확인된 라이선스와 출처 URL이 필요합니다. 결과물은 오프라인 단일 HTML을 유지하고 판단 근거를 design-reference.json에 기록합니다.

개인·내부 업무는 무료입니다. 도구 유료 제공·외부 생성 서비스는 별도 서면 허가가 필요합니다.
