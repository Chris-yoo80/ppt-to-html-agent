# 피드백 반영 업데이트 릴리스 노트 초안

브랜치: `feat/feedback-1025`  
상태: 로컬 커밋만 완료했으며 push·병합·배포하지 않았습니다.

## 변경 내용

- 수치 검수에 금액, 물리·복합·업무 단위, 분모 정의, 필터 범위, 화면 반올림과 원본 시트/범위를 포함했습니다. 최종 보고는 항목마다 통과 또는 확인 필요와 근거를 표시합니다.
- 배송·마케팅·창고와 발표 예제에서 모션 끔, 모션 줄이기, 인쇄/PDF 상태에도 핵심 제목·수치·설명이 남습니다.
- 전체 장면·단계 목차와 정확한 단계의 질문 북마크를 발표 플레이어에 추가했습니다. 단축키는 목차 `G`, 질문 표시 `B`, 목록 `Shift+B`, 최근 질문 복귀 `R`입니다.
- 한·영 README와 소개 페이지에 3단계 빠른 시작, Claude Code/Codex 설치 경로와 확인된 제한을 넣었습니다.
- 두 달치 가상 JSON·`.xlsx`, 공통 5장 생성기, 한·영 발표 JSON, 오프라인 HTML 4개로 월간 매출 리포트 반복 생성 흐름을 추가했습니다.
- 목차 → 개요 → 본문 → 타임라인 → 결론의 가상 7장 전체 발표 예제를 추가했습니다.

## 검증

- Python 테스트 23개 통과
- Node 테스트 30개 통과: 모션 12개, 플레이어·분석 18개
- 지정된 Development checks 6개 모두 통과
- HTML 22개, 로컬 참조 64개, 결정적인 모션 생성물, 휴대용 스킬 ZIP 35개 항목 검사 통과
- 스킬 유효성 검사 통과
- 수정한 월간 요약과 타임라인을 Microsoft Edge 1600×900 헤드리스 환경에서 확인하고 겹침·잘림을 수정했습니다.

## 남은 제한

- 저장한 다중 페이지 PDF, 여러 브라우저와 실제 모바일 기기는 별도 시각 검토가 필요합니다.
- 원본 PPT 배치의 픽셀 단위 복원, 이미지 OCR, 임의 차트·엑셀 수식 해석은 지원하지 않습니다.
- 구버전 `.ppt`, 암호/DRM 파일, MP4 출력과 일반 ChatGPT·Claude 웹 채팅 실행은 지원하지 않습니다.
- 수치 메타데이터와 자동 산술 검사는 승인된 원본 엑셀과의 대조를 대신하지 않습니다.
