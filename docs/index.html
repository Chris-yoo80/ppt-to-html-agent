02 / THE AGENT WORKFLOW

디자인보다 먼저,
무엇을 설명할지 정합니다.

AI가 만드는 과정에도 기준이 필요하니까.
확인 가능한 절차를 스킬로 묶었습니다.

  1. 01

    Read

    PPT의 내용과 표, 메모를 읽고 원문 근거를 정리합니다.

  2. 02

    Direct

    핵심 메시지와 설명 순서, 적합한 모션을 제안합니다.

  3. 03

    Build

    검토한 구성을 단계별 HTML 발표로 제작합니다.

  4. 04

    Refine

    수치·화면 넘침·단계 진행을 점검하고 수정합니다.

가상 예제로 두 CLI의 변환·수정을 확인했습니다. 마케팅 보충 HTML의 실제 Edge 조작도 검증했습니다. 상세 범위와 한계는 검증 기록을 확인하세요.

수치 검수: 금액뿐 아니라 길이·면적·부피·질량·시간·복합 단위도 확인합니다. 지원 환산은 제공된 값을 대조하고, 정의가 없는 단위는 확인 필요로 남깁니다. 분모·필터·반올림·출처도 함께 검수합니다. 검수 결과 보기 ↗

GOOD TO KNOW
몇 가지, 분명하게.
이 페이지에서 바로 PPT를 변환하나요?
아니요. 이곳은 소개·예제 체험·시작 요청문 생성 페이지입니다. 실제 변환은 스킬을 설치한 AI 환경에서 수행합니다.
원본 PPT와 똑같은 배치를 복원하나요?
내용을 바탕으로 설명 구조와 화면을 재설계합니다. 원본 배치의 완전 복원은 지원하지 않습니다. 기본 추출기는 PPTX의 텍스트·표·메모를 읽으며 이미지 OCR과 차트 데이터 해석은 포함하지 않습니다.
동영상 파일도 만들 수 있나요?
첫 버전은 HTML 안의 점·선·면 모션 그래픽에 집중합니다. MP4 영상 파일 출력은 후속 기능입니다.
어떤 내용이 GitHub에 공개되나요?
일반적인 제작 지침과 코드, 새로 작성한 가상 예제만 공개합니다. 사용자의 실제 PPT·메모·내장 자료는 공개 예제로 자동 전환하지 않습니다.
