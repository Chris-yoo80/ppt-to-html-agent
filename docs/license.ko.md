# 사용 조건 안내

적용 라이선스는 **PPT to HTML Agent Community License 1.0 — Internal Use and Presentation Output Exception**입니다. 합의한 사용 범위를 담아 작성한 프로젝트 전용 라이선스 초안이며, 법률 전문가의 검토를 받은 표준 라이선스는 아닙니다. 실제 적용 조건은 [영문 LICENSE](../LICENSE)가 기준입니다.

| 이용 방식 | 조건 |
|---|---|
| 개인 학습·실험·비상업적 활동 | 무료 허용 |
| 영리기업을 포함한 회사 내부 업무에 사용·수정 | 무료 허용 |
| 비상업적 목적으로 스킬·코드를 무료 재배포 | 라이선스·저작권 고지 유지 및 주요 수정 표시 |
| 생성한 발표물을 보고·제안·교육·고객 발표에 공유·전달 | HTML에 포함된 플레이어를 함께 전달하는 예외 허용 |
| 에이전트·수정판·플레이어를 도구로 재판매하거나 유료 제품에 포함 | 별도 서면 허가 필요 |
| 외부 고객을 대상으로 생성·변환 서비스를 사업으로 운영 | 별도 서면 허가 필요 |

## 발표 결과물과 도구의 구분

발표 내용을 담은 HTML에는 플레이어 코드가 들어갑니다. 생성 결과물을 업무나 고객 발표에 전달할 때 이 코드까지 함께 배포할 수 있도록 결과물 예외를 두었습니다. 받은 사람도 같은 발표를 열고 공유할 수 있습니다.

플레이어를 따로 추출해 도구로 판매하거나, 발표 파일을 가장해 생성 서비스를 배포하는 것은 이 예외에 포함되지 않습니다. 에이전트 코드를 공개하지 않고 서버에서 실행하는 서비스도 외부 생성·변환 사업이라면 별도 허가 대상입니다.

사용자 PPT·입력 데이터·독자적으로 작성한 발표 내용의 권리를 이 라이선스로 가져오지 않습니다. 입력 자료와 제3자 이미지·글꼴 등의 이용 권한은 별도로 확보해야 합니다.

소개 페이지와 가상 데모의 Story Sans는 Pretendard 1.3.9를 바탕으로 글자 범위를 줄이고 이름을 변경한 예제용 글꼴입니다. 글꼴은 별도의 [SIL OFL 1.1](fonts/OFL.txt)을 유지하며 프로젝트 라이선스의 재판매 제한을 글꼴 자체에 적용하지 않습니다. 현재 예제에 없는 글자는 시스템 글꼴로 표시됩니다.

## 고지와 워터마크

도구와 결과물에는 라이선스·저작권 고지를 유지해야 합니다. 생성기는 HTML 소스에 법적 고지와 라이선스 전문을 포함합니다. 눈에 보이는 이니셜 워터마크는 이번 조건에서 의무화하지 않았으며, 표시 문구는 별도로 결정합니다. 스타·홍보·회사 자료 공개 의무는 없습니다.

## 프로젝트 소개 문구

이용 목적에 따른 제한이 있으므로 MIT나 OSI 기준 오픈소스로 표기하지 않습니다. **'개인·내부 업무에 무료로 쓸 수 있는 소스 공개 에이전트'**로 안내합니다. AI 구독료·API·호스팅 요금은 각 서비스의 조건을 따릅니다.
