PPT TO HTML AGENT / USER GUIDE

A presentation, with its supporting analysis.

Use the skill in your AI environment. Keep the presentation concise, then open an additional HTML analysis whenever you need the evidence.

Download the skill ZIP and copy the complete ppt-to-html/ folder into your working project:

Open that project in the selected host and provide an accessible PPTX. Python 3.10+ is needed for bundled helpers. The website does not upload or convert files. Your AI provider’s subscription or usage charges still apply. Installation links require an internet connection.

2. Start with the brief

Use the ppt-to-html skill to reconstruct this PPT as an HTML presentation.
Ask only for missing settings: purpose, audience, time, screen size,
typeface, motion frequency, playback and supporting material.
I want marketing analysis as additional HTML inside the presentation.
Place controls and slicers on the left, visual results on the right.
Show the outline and one representative scene before building the rest.

For the supporting analysis, first provide the workbook as a chat attachment or accessible local path. The agent asks which sheets/ranges to use and where to place the analysis: Additional resources, a standalone HTML link, or both. Specify the related scene/topic and resource tab label. Then agree on period, currency, KPI definitions, filters, screen, font, language and sharing scope. This is an agent conversation step, not a workbook upload control on this website. The current player uses a presentation-wide resources button; scene-specific controls require a separate extension. Accept recommended defaults in one answer if you prefer. Reuse answers already supplied.

3. Build the basics, then extend

01 / Agree

Confirm the brief, source meaning and layout.

02 / Review

Check an outline and a representative scene or chart.

03 / Extend

Add detail, scenarios and exports after the base is accepted.

The finished deliverables are presentation HTML, supporting-analysis HTML and editable sources. Supporting HTML can be embedded in the presentation, so the main file works offline without a sidecar server.

5. Explore the marketing supplement

On first open, choose purpose, priority metrics, viewing context, font and CSV controls. On the left, select period, channels and market. On the right, review KPIs, revenue/spend trends, conversion counts and channel ROAS. Add the source detail table only when needed.

What-if sliders keep source results unchanged. They assume constant cost per click and channel mix, with separate conversion and order-value multipliers. These are hypothetical scenarios, not forecasts. ROAS uses total revenue / total spend; conversion uses total purchases / total clicks. A zero denominator is unavailable.

Save HTML retains the current brief, filters and assumptions in one file. CSV downloads are opt-in in Initial setup. The source workbook is not automatically attached.

6. Share the right information

Offline HTML contains the data needed for its charts. Turning off CSV buttons does not remove that data or secure confidential information.

Review notes, hidden sheets, embedded files, personal information, internal paths and source attachments before sharing. Include raw PPT or Excel files only when explicitly selected and reviewed. Public examples in this project use newly authored fictional data.

7. PDF output and backup tabs

At the start, tell the agent whether you need a deck PDF, analysis PDF, or both. Specify backup files, their related scene/topic, tab labels and placement (Additional resources, a separate HTML link, or both). The agent asks for missing answers and reuses known settings. Raw PPT/Excel attachments remain a separate opt-in choice.

In the presentation, choose Print / PDF to preview all scenes with every reveal visible, one scene per A4 landscape page. Choose Print / Save as PDF, select the browser's PDF destination, and save. Return to the same presentation step; autoplay remains paused. Browser headers/footers can be disabled in the print dialog.

Print supporting analysis separately using its Print / PDF control, or open its standalone HTML. It uses the current filters and enabled detail/scenario sections. Motion and slicers become static results. Backup resources are labeled HTML tabs (up to eight); the example includes source/calculation notes. They are not automatically merged into the deck PDF. Review each resource's own print layout before sharing.

8. Verify the numbers

Before delivery, compare units and any displayed conversion, denominators, filters/ranges, rounding and source references against the original workbook. In Definitions and evidence, inspect source units, conversion precision, rate definitions, current filters, source totals and sheet/range. Amounts are sourced in KRW; Korean views abbreviate amounts of at least KRW 10,000 in units of 10,000 (max one decimal), English views abbreviate amounts of at least KRW 1,000,000 in millions (max two decimals). Trend axes use those divisors with max one decimal; rates use max two decimals. Ratios use the same selected group, not an average of row ratios.

The agent's final report must include five rows: units / denominators / filters and ranges / rounding / provenance, each with Passed or Needs review and supporting evidence. Metadata describes the implementation; it does not automatically certify agreement with your workbook. Rounded parts may differ from the rounded total; calculations retain source precision. Missing source definitions or checks remain Needs review.

9. Supported scope

The skill redesigns the narrative rather than reproducing PPT pixels. Basic PPTX extraction reads text, tables and separate notes; OCR, SmartArt text and chart workbook interpretation are not included. The campaign starter accepts a reviewed data model; it does not automatically interpret arbitrary Excel formulas, macros or external connections. Other workbook types require a separately validated adapter. MP4 export is deferred.

Static checks, host CLI tests and real browser checks cover different things. See the verification record for the exact observations; a single fictional example does not establish compatibility with every workbook or browser.
