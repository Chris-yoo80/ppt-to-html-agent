# GitHub 공개 계획 — 협의용 초안

## 공개 형태

- 저장소 가칭: `ppt-to-html-agent`.
- 소개: PPT를 인터랙티브 HTML 발표로 재구성하는 에이전트. Claude Code·Codex용 스킬로 제공.
- 첫 지원 대상: 파일을 읽고 코드를 실행할 수 있는 Claude Code·Codex 환경. 두 환경에서 실행 검증 후 지원 표기.
- 첫 버전은 공통 스킬·제작 도구·가상 예제와 GitHub Pages 소개·체험 페이지로 구성. 독립 앱과 API 연결은 후속 단계.
- 스킬·코드는 개인·내부 업무 무료 사용 조건으로 소스 공개. 에이전트 재판매·유료 제품 포함·외부 생성 서비스 사업은 별도 서면 허가. AI 구독·API 요금은 사용자 환경의 조건에 따름. 페이지에는 AI 호출이나 PPT 업로드를 넣지 않음.
- 라이선스 방향은 사용자와 확정. 프로젝트 전용 Community License 1.0 초안을 작성하고 발표 결과물 배포 예외를 포함. MIT·OSI 승인 오픈소스로 표기하지 않음. 별도 법률 검토는 받지 않음.
- 첫 버전은 HTML 내부 모션만 지원. MP4 출력은 사용자 결정에 따라 다음 버전으로 연기.
- 사용자가 배송·마케팅·창고 모션을 대표 데모로 확정. 소개 첫 화면과 README는 '이야기는 움직이고. 설명은 내 속도로.'를 중심으로 재생·정지·단계 선택의 가치를 먼저 보여줌.
- ChatGPT 등 다른 환경은 설치 방식과 도구 지원을 검증한 뒤 안내. 모든 일반 채팅에서 동일하게 실행된다고 표시하지 않음.

## 작업 순서

1. 시작 질문과 기본 설정, 모션 출력 범위를 사용자와 확정.
2. 일반화된 내용 추출·발표 구조·단계 엔진·SVG 모션·배포 과정을 구현.
3. 완전히 새로 작성한 가상 PPT 하나로 입력부터 HTML 검증까지 실행. 현재 완료된 예제는 가상 Markdown → scene JSON → HTML 범위.
4. Claude Code·Codex에서 각각 사용하고, 원문 충실도·넘침·동작·수정 반영을 비교.
5. 실제 지원 범위에 맞춰 README, 설치 안내, 전후 화면, 데모, LICENSE 작성. README·설치 안내·정적 소개 페이지·HTML 데모·스킬 ZIP·프로젝트 전용 LICENSE 초안을 작성.
6. 이 폴더만 저장소로 초기화하고 공개 파일 목록 및 커밋 대상 검사. 상위 폴더에서 `git add .` 하지 않음.
7. 사용자 소유 GitHub 계정과 저장소명을 확인하고 검토 가능한 첫 커밋을 업로드. 2026-10-22 사용자 공개 배포 승인. 공개 전용 폴더만 저장소로 초기화.

## 확인할 결정

- 저장소 최종 이름과 공개 시점. 현재 영어 메인 + 한국어 문서 구성.
- 눈에 보이는 워터마크의 정확한 이니셜·문구는 미정. 현 라이선스는 법적 고지 유지만 요구하고 시각적 워터마크는 의무화하지 않음.
- PPT 입력부터의 평가에 쓸 새 가상 PPT 작성. 현재 도서관 기본 예제와 배송·마케팅·창고 모션 예제는 새로 작성한 시나리오·설정에서 생성한 HTML이며 PPT 자동 추출 결과가 아님.

## 현재 부족한 부분

PPTX 텍스트·표·메모 추출기, 제한된 scene JSON을 단일 HTML로 만드는 생성기와 가상 도서관 예제를 구현했다. 추출기는 렌더링·OCR·차트 워크북·SmartArt 텍스트 해석을 지원하지 않는다. SmartArt와 숨긴 장표는 별도 표시한다. 발표 흐름 판단은 호스트 AI가 수행한다. 스크립트 검사 결과는 검증 기록에 남긴다. 기존 발표 HTML은 로컬 참고 자료이며 공개 패키지에 포함하지 않는다. 브라우저 보안 정책으로 로컬 HTML 화면 검증이 차단된 세션에서는 이를 우회하지 않고 미검증 항목을 명시한다. Claude CLI로 공개 코드 4개 파일의 읽기 전용 검토를 받았고 확인된 결함을 수정했다. Claude·Codex에서 전체 변환 흐름을 실행하는 검증은 아직 미완료.

통과한 검사와 아직 실행하지 못한 항목은 [verification.md](verification.md)에 구분했다. 한국어·영어 초기 공개 버전으로 배포한다. 실제 배포 결과는 verification.md에 기록한다.
